KTransformers

KTransformers 是面向大模型异构推理与微调的框架。昇腾上的安装、权重准备和启动命令以上游官方教程为准。

阅读官方教程前，先按 快速安装昇腾环境 准备 CANN 与驱动。

项目主页：KTransformers 文档站。

硬件决定走哪一篇教程。上游已验证的昇腾路径目前是 Atlas 300I A2，以及单卡约 64 GB HBM 的 Atlas 800I A2 / Atlas A3。
